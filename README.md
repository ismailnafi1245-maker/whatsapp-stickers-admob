# whatsapp-stickers-admob
WhatsApp Stickers Android App with Google AdMob Ads Integration.

## Features
- **Banner Ad**: Configured at the bottom of all activities using official test unit ID `ca-app-pub-3940256099942544/6300978111`.
- **Interstitial Ad**: Shown when user taps "Add to WhatsApp" using test unit ID `ca-app-pub-3940256099942544/1033173712`.
- **Play Services Ads**: Upgraded to `com.google.android.gms:play-services-ads:23.0.0` with `minSdkVersion 21`.
- **Two Complete Sticker Packs**: Cuppy and Together at Home (Animated).

## Project Setup
1. Open this repository or extract the project in Android Studio.
2. Sync Gradle dependencies.
3. Replace the Google Test Ad IDs in `app/src/main/res/values/strings.xml` and `app/src/main/AndroidManifest.xml` with your real AdMob account IDs before publishing to Google Play Store!
